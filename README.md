# 汉化补丁 / 预翻译存档

本仓库是 [flamecho](https://www.flamecho.top) 的个人\汉化补丁与预翻译文件存档，
配合博客的「[汉化发布页](https://www.flamecho.top/p/trans)」使用。

- **内容**：汉化补丁与预翻译文件（zip 包），文件名即游戏名，可直接下载。
- **不包含**：任何游戏本体，也没有破解或绕过正版验证的内容 —— 只有补丁与预翻译文件。
- **怎么拿**：文件以 [Releases](https://github.com/flamecho/flamecho-translation-patch/releases) 附件形式提供；
  也可以先在[发布页](https://www.flamecho.top/p/trans)按游戏名检索，再点「汉化获取」跳转到对应文件。

补丁基于个人兴趣制作与整理，非商业用途，翻译质量不作保证；请先购买并支持正版。
若权利方认为其中内容不妥，欢迎通过 Issues 联系，我会尽快移除。
